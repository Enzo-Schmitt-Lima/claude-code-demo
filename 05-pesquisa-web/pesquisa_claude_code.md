## Resumo dos resultados

Claude Code é a ferramenta agêntica de programação da Anthropic — disponível como
CLI, extensão de IDE e app desktop. Ele lê arquivos, executa comandos, edita
código e chama ferramentas externas de forma autônoma.

Destaques recentes (2026):
- **Sub-agentes aninhados** (até 3 níveis) para decompor tarefas em camadas.
- **fallbackModel** para cadeias de modelos resilientes.
- **Marketplace de ferramentas** da comunidade.
- **Atribuição de uso** por agente/tarefa, com detalhamento de custo.
- **App desktop redesenhado** (abril de 2026) para macOS e Windows, com sessões
  isoladas via Git worktrees — cada sessão trabalha numa cópia própria do
  repositório.
- Expansão de recursos de **compliance/enterprise** cobrindo desktop, web,
  mobile e CLI.
